生字列表

【たかが】 (たかが / takaga)

  • 詞性： 副詞
  • 廣東話解釋： 區區、充其量只不過是……
  • 歌詞語境： たかが知人B 即係「區區一個熟人B」，突顯男主角覺得自己連朋友都未算得上。
  • 例句：
    • 🇯🇵 日： たかが風邪だと甘く見てはいけない。
    • 🇭🇰 粵： 唔好以為只係區區感冒就掉以輕心。

【向けられた】 (むけられた / mukerareta)

  • 詞性： 動詞（向ける 的被動態過去式）
  • 廣東話解釋： 被朝向、被針對、被給予
  • 歌詞語境： 知人Bにむけられた笑顔 即係「朝住熟人B展露嘅笑容」。
  • 例句：
    • 🇯🇵 日： 彼に向けられた批判はとても厳しかった。
    • 🇭🇰 粵： 針對佢嘅批評非常嚴厲。

【あれ】 (are)

  • 詞性： 代名詞
  • 廣東話解釋： 那個；喺呢度引申做「那種程度／那副樣子」
  • 歌詞語境： 笑顔があれなら 即係「如果佢個笑容係去到嗰種級數」，男主角覺得殺傷力太誇張。
  • 例句：
    • 🇯🇵 日： 彼の運動神経はあれだよ、人間じゃない。
    • 🇭🇰 粵： 佢嘅運動神經去到「嗰種級數」，已經唔似人類。

【惚れさせる】 (ほれさせる / horesaseru)

  • 詞性： 動詞（使役形）
  • 廣東話解釋： 令（某人）愛上、迷上
  • 歌詞語境： 君を惚れさせる黒魔術 即係「令你愛上我嘅黑魔法」。
  • 例句：
    • 🇯🇵 日： 好きな子を惚れさせるために、毎日ギターを練習している。
    • 🇭🇰 粵： 為咗令鍾意嘅女仔愛上我，我日日練結他。

【連れ去られ】 (つれさられ / tsuresarare)

  • 詞性： 動詞（連れ去られる 的連用形）
  • 廣東話解釋： 被帶走、被擄走，然後……
  • 歌詞語境： 夏の魔物に連れ去られ 係男主角幻想女生被「夏天嘅魔物」帶到自己身邊。
  • 例句：
    • 🇯🇵 日： お姫様は魔王に連れ去られた。
    • 🇭🇰 粵： 公主畀魔王擄走咗。

【やら】 (yara)

  • 詞性： 副助詞
  • 廣東話解釋： ……之類、叫做什麼……
  • 歌詞語境： 夏の魔法とやら 帶少少「我都知未必真有呢樣嘢」嘅語氣。
  • 例句：
    • 🇯🇵 日： 山田とやらいう人から電話がありましたよ。
    • 🇭🇰 粵： 有個叫咩山田之類嘅人打過電話嚟。

【焼けた肌】 (やけたはだ / yaketa hada)

  • 詞性： 名詞
  • 廣東話解釋： 曬黑嘅皮膚、小麥色肌膚
  • 歌詞語境： 男主角幻想情敵係個陽光型男，焼けた肌 同佢非常襯。
  • 例句：
    • 🇯🇵 日： 夏休みに海へ行って、すっかり焼けた肌になった。
    • 🇭🇰 粵： 暑假去咗海邊，皮膚完全曬黑咗。

【背伸びしている】 (せのびしている / senobi shiteiru)

  • 詞性： 動詞句
  • 廣東話解釋： 踮起腳尖；亦可引申做逞強、扮成熟
  • 歌詞語境： 呢度係字面意思，幻想女主角接吻時要踮高腳先夠到對方。
  • 例句：
    • 🇯🇵 日： 棚の上の本を取るために背伸びする。
    • 🇭🇰 粵： 為咗拎高處本書而踮起腳尖。

【なでられ】 (なでられ / naderare)

  • 詞性： 動詞（なでられる 的連用形）
  • 廣東話解釋： 被撫摸（頭），然後……
  • 歌詞語境： 頭をなでられ 描寫女主角被摸頭後露出笑容嘅畫面。
  • 例句：
    • 🇯🇵 日： 犬は飼い主に頭をなでられて、嬉しそうに尻尾を振った。
    • 🇭🇰 粵： 隻狗畀主人摸頭之後，開心咁搖尾。

【アブラカタブラ】 (aburakatabura)

  • 詞性： 名詞 / 外來語
  • 廣東話解釋： 咒語、魔法詞（Abracadabra）
  • 歌詞語境： 男主角將希望寄託喺超現實嘅魔法力量上。
  • 例句：
    • 🇯🇵 日： マジシャンは「アブラカタブラ」と唱えて、帽子から鳩を出した。
    • 🇭🇰 粵： 魔術師念咗句「Abracadabra」，之後喺帽入面變出隻鴿。

【胸の焦り】 (むねのあせり / mune no aseri)

  • 詞性： 名詞
  • 廣東話解釋： 內心嘅焦躁、著急、按捺不住嘅衝動
  • 歌詞語境： 形容男主角好想即刻衝去見對方嗰種心急。
  • 例句：
    • 🇯🇵 日： 連絡が来なくて、胸の焦りが募るばかりだ。
    • 🇭🇰 粵： 一直收唔到聯絡，心入面愈嚟愈焦急。

【身を任せ】 (みをまかせ / mi o makase)

  • 詞性： 慣用語（身を任せる 的連用形）
  • 廣東話解釋： 任由……驅使、順從於……
  • 歌詞語境： 胸の焦りに身を任せ 即係任由內心焦躁推住自己行動。
  • 例句：
    • 🇯🇵 日： 音楽に身を任せて踊る。
    • 🇭🇰 粵： 順住音樂節奏咁跳舞。

【舞い上がってました】 (まいあがってました / maiagatte mashita)

  • 詞性： 動詞
  • 廣東話解釋： 被沖昏頭腦咗、得意忘形咗
  • 歌詞語境： 男主角擔心其實只係自己一廂情願，被「夏天魔法」搞到失晒分寸。
  • 例句：
    • 🇯🇵 日： 先生に褒められて、つい舞い上がってしまった。
    • 🇭🇰 粵： 畀老師讚完，一唔小心就得意忘形咗。

【オチ】 (ochi)

  • 詞性： 名詞
  • 廣東話解釋： 結局、下場；原意亦可指笑點、包袱
  • 歌詞語境： 怖すぎるオチばかり 即係腦海入面全都係好尷尬、好慘嘅收場。
  • 例句：
    • 🇯🇵 日： 一生懸命走ったのに、電車に乗り遅れるという悲しいオチだった。
    • 🇭🇰 粵： 明明死命跑，結果都係趕唔切車，收場好慘。

【浮かんできて】 (うかんできて / ukande kite)

  • 詞性： 動詞
  • 廣東話解釋： 不斷浮現出嚟
  • 歌詞語境： 各種可怕下場不停喺男主角腦海冒出嚟。
  • 例句：
    • 🇯🇵 日： 新しいアイデアが次々と浮かんできて、眠れない。
    • 🇭🇰 粵： 新諗法一個接一個浮現出嚟，搞到瞓唔著。

【真夏】 (まなつ / manatsu)

  • 詞性： 名詞
  • 廣東話解釋： 盛夏、大夏天、最熱嘅夏天
  • 歌詞語境： 真夏の空の下で 點出場景係炎炎夏日。
  • 例句：
    • 🇯🇵 日： 真夏の太陽がギラギラと照りつけている。
    • 🇭🇰 粵： 盛夏嘅太陽猛烈咁照住。

【震え】 (ふるえ / furue)

  • 詞性： 名詞 / 動詞連用形
  • 廣東話解釋： 發抖、顫抖
  • 歌詞語境： 明明係盛夏，男主角卻因為緊張同焦慮而震住咁諗對方。
  • 例句：
    • 🇯🇵 日： 緊張のあまり、声が震えてしまった。
    • 🇭🇰 粵： 因為太緊張，連把聲都震埋。
