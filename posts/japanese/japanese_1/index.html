字典說明

呢個字典專門用最地道嘅廣東話嚟解釋日文生字，幫大家更快掌握日文嘅真正語感。

【物事】 (ものごと / monogoto)

  • 詞性： 名詞
  • 廣東話解釋： 事物、事情（廣泛指抽象嘅事物，即係「大大小小嘅事」）。
  • 例句：
    • 🇯🇵 日： 物事をいい方に考える。
    • 🇭🇰 粵： 凡事向好嗰方面諗。

【編成する】 (へんせいする / hensei suru)

  • 詞性： 他動詞 / 名詞（編成）
  • 廣東話解釋： 編排、組成（通常指節目表、隊伍、組織等，即係「排陣」、「編組」）。
  • 例句：
    • 🇯🇵 日： 新しいチームを編成する。
    • 🇭🇰 粵： 組一隊新嘅 team（隊伍）。

【穴埋め】 (あなうめ / anaume)

  • 詞性： 名詞 / する動詞
  • 廣東話解釋： 填補空缺、補償（例如填表嘅「填充題」，或者填補虧損、補返個位）。
  • 例句：
    • 🇯🇵 日： 赤字の穴埋めをする。
    • 🇭🇰 粵： 填補赤字 / 填氹。

【支える】 (ささえる / sasaeru)

  • 詞性： 他動詞
  • 廣東話解釋： 支撐、支持（可以係物理上「撐住」，或者精神/經濟上嘅「back up」、「支持住」）。
  • 例句：
    • 🇯🇵 日： 家族が私を支えてくれた。
    • 🇭🇰 粵： 屋企人一直支持住我 / 撐我。

【層】 (そう / sō) [基層]

  • 詞性： 名詞
  • 廣東話解釋： 階層、層（例如社會階層、年齡層。你提到嘅「基層」即係社會最底層嘅大眾，或者基礎層面）。
  • 例句：
    • 🇯🇵 日： 幅広い層から支持される。
    • 🇭🇰 粵： 受到唔同階層嘅人支持。
Tip語感補充

如果指社會嘅「基層」，日文通常會用「草の根（くさのね）」或者直接講「低所得者層（ていしょとくしゃそう）」。

【厚さ】 (あつさ / atsusa) [雄厚、龐大]

  • 詞性： 名詞
  • 廣東話解釋： 厚度（喺呢個語境下，引申為實力「雄厚」、陣容「鼎盛 / 龐大」）。
  • 例句：
    • 🇯🇵 日： 選手層の厚さを見せつけた。
    • 🇭🇰 粵： 展現出球員陣容有幾鼎盛（板凳深度好夠）。

【単行本】 (たんこうぼん / tankōbon)

  • 詞性： 名詞
  • 廣東話解釋： 單行本（連載漫畫或者雜誌文章結集出版嘅書，即係平時買嗰啲「一本本嘅漫畫」或者獨立成書嘅出版物）。
  • 例句：
    • 🇯🇵 日： この漫画の単行本を買う。
    • 🇭🇰 粵： 買呢套漫畫嘅單行本。

【競争原理】 (きょうそうげんり / kyōsōgenri)

  • 詞性： 名詞
  • 廣東話解釋： 競爭法則、競爭機制（即係「物競天擇」、「有競爭先有進步」嗰種市場規則）。
  • 例句：
    • 🇯🇵 日： 市場に競争原理が働く。
    • 🇭🇰 粵： 市場發揮緊競爭機制嘅作用。

【生み出す】 (うみだす / umidasu)

  • 詞性： 他動詞
  • 廣東話解釋： 產生、創造出嚟（即係「搞啲新嘢出嚟」、「生出嚟」）。
  • 例句：
    • 🇯🇵 日： 新しいアイデアを生み出す。
    • 🇭🇰 粵： 度啲新橋出嚟 / 創造新嘅 idea。

【〜のみ】 (nomi)

  • 詞性： 助詞
  • 廣東話解釋： 只、僅僅（比較 formal 嘅講法，等於「だけ」，即係「淨係得…」）。
  • 例句：
    • 🇯🇵 日： 平日のみ営業しています。
    • 🇭🇰 粵： 淨係得閒日先開門（做生意）。

【過剰】 (かじょう / kajō)

  • 詞性： 名詞 / な形容詞
  • 廣東話解釋： 過剩、過多（即係「多得滯」、「超標」）。
  • 例句：
    • 🇯🇵 日： 彼は自信過剰だ。
    • 🇭🇰 粵： 佢自信心爆棚（自信過多）。

【次週】 (じしゅう / jishū)

  • 詞性： 名詞
  • 廣東話解釋： 下週（即係「下個禮拜」）。
  • 例句：
    • 🇯🇵 日： 次週の放送をお楽しみに。
    • 🇭🇰 粵： 請期待下個禮拜嘅播出。

【蓄積する】 (ちくせきする / chikuseki suru)

  • 詞性： 名詞 / する動詞
  • 廣東話解釋： 累積、積聚（通常指疲勞、財富、知識等，即係「儲儲埋埋」）。
  • 例句：
    • 🇯🇵 日： 疲労が蓄積している。
    • 🇭🇰 粵： 啲疲勞儲儲埋埋搞到好攰。

【亜流】 (ありゅう / aryū)

  • 詞性： 名詞
  • 廣東話解釋： 次等、模仿者、二流（模仿一流作品但質素唔夠好嘅嘢，即係「翻版」、「山寨」、「A貨」）。
  • 例句：
    • 🇯🇵 日： それはピカソの亜流にすぎない。
    • 🇭🇰 粵： 嗰個只不過係畢加索嘅山寨貨（模仿作）。

【別冊】 (べっさつ / bessatsu)

  • 詞性： 名詞
  • 廣東話解釋： 附錄、別冊（跟住雜誌或者書另外出一本嘅特刊，即係「附送嘅特別版書仔」）。
  • 例句：
    • 🇯🇵 日： 雑誌の別冊付録。
    • 🇭🇰 粵： 雜誌附送嘅別冊 / 書仔。

【取り上げる】 (とりあげる / toriageru) [舉例]

  • 詞性： 他動詞
  • 廣東話解釋： 提及、提出嚟講（喺你要求嘅語境下，指將某個話題或者例子「攞出嚟講 / 當例子舉出嚟」）。
  • 例句：
    • 🇯🇵 日： 彼を例として取り上げる。
    • 🇭🇰 粵： 攞佢做例子提出嚟講。

【役】 (やく / yaku) [角色]

  • 詞性： 名詞
  • 廣東話解釋： 角色、職責（即係做戲嘅「角色」，或者分擔嘅「任務 / 崗位」）。
  • 例句：
    • 🇯🇵 日： 主役を演じる。
    • 🇭🇰 粵： 擔正做主角。

【最中】 (さいちゅう / saichū)

  • 詞性： 名詞
  • 廣東話解釋： 正當…嘅時候（即係「做做吓…嗰陣」、「正喺度…緊」）。
  • 例句：
    • 🇯🇵 日： 会議の最中に電話が鳴った。
    • 🇭🇰 粵： 開開吓會嗰陣個電話響。

【活気】 (かっき / kakki)

  • 詞性： 名詞
  • 廣東話解釋： 活力、生氣（形容個地方或者氣氛好熱鬧，即係「好有生氣」、「好旺」）。
  • 例句：
    • 🇯🇵 日： この町は活気がある。
    • 🇭🇰 粵： 呢個區/市鎮好有生氣（好熱鬧）。

【生き生きする】 (いきいきする / ikiiki suru)

  • 詞性： する動詞 / 副詞 (生き生きと)
  • 廣東話解釋： 生動、充滿活力（形容人或者動植物好精神，即係「生猛」、「好有活力」）。
  • 例句：
    • 🇯🇵 日： 子どもたちが生き生きと遊んでいる。
    • 🇭🇰 粵： 班細路玩得好生猛（好有活力）。

【実写】 (じっしゃ / jissha)

  • 詞性： 名詞
  • 廣東話解釋： 真人版、實景拍攝（通常指動漫改編做真人演嘅戲，即係「真人版」）。
  • 例句：
    • 🇯🇵 日： あのアニメが実写化される。
    • 🇭🇰 粵： 嗰套動漫會拍成真人版。

【通り過ぎる】 (とおりすぎる / tōrisugiru)

  • 詞性： 自動詞
  • 廣東話解釋： 行過、經過（即係「行過咗」、「過龍」）。
  • 例句：
    • 🇯🇵 日： 駅を通り過ぎてしまった。
    • 🇭🇰 粵： 搭車搭過咗龍（過咗個站）。
