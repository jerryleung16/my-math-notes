歌曲簡介

  • 呢首〈マリーゴールド〉係あいみょん 2018年嘅代表作，歌詞圍繞住夏天、麥稈帽同戀人之間嘅深情，畫面感強烈，充滿青春戀愛嘅溫度。
  • 「麦わらの帽子の君がマリーゴールドに似てる」係全首歌最標誌性嘅一句，將戀人同夏天陽光下搖擺嘅萬壽菊相連，唯美而充滿少女感。
  • 「本当の気持ち全部吐き出せるほど強くはない」流露咗戀愛中嘅脆弱，唔係所有感情都可以坦然講出口，呢種真實令歌詞更加貼地。
  • 副歌「雲のような優しさでそっとぎゅっと抱きしめて」對比強烈，「雲のような優しさ」係輕柔嘅形容，配上「ぎゅっと」嘅緊抱動作，表現咗保護與溫柔並存嘅愛。
  • 「アイラブユーの言葉じゃ足りないからとキスして」唔用說話而用行動，講出咗愛深到語言都表達唔到嘅感覺。
  • 最後「いつまでも いつまでも 離さない」重複收結，帶出一種想永遠留住這一刻、不願分離嘅執念，係整首歌情感最高點。

生字列表

【揺さぶり】 (ゆさぶり / yusaburi)

  • 詞性： 動詞（揺さぶる 的連用形）
  • 廣東話解釋： 搖動、震撼、強烈地撼動（身體或心靈）
  • 歌詞語境： 心を揺さぶりすぎて 係講風嘅力度太強，搖撼住心裡嘅感受太多，超出承受範圍，帶出一種被情緒左右嘅狀態。
  • 例句：
    • 🇯🇵 日： その映画は、見る人の心を深く揺さぶった。
    • 🇭🇰 粵： 嗰套電影深深撼動咗觀眾嘅心。

【恋しい】 (こいしい / koishii)

  • 詞性： 形容詞（い形）
  • 廣東話解釋： 想念、掛念、思念到想見對方
  • 歌詞語境： 真面目に見つめた君が恋しい 係講那個認真望住自己嘅你，令人好掛念、好想再見，流露出深深嘅思念之情。
  • 例句：
    • 🇯🇵 日： 遠くにいる君が、どうしても恋しくなる。
    • 🇭🇰 粵： 在遠方嘅你，讓我忍不住好掛念。

【でんぐり返し】 (でんぐりがえし / denguri gaeshi)

  • 詞性： 名詞
  • 廣東話解釋： 前滾翻、翻筋斗；引申為生活翻來覆去、亂糟糟嘅狀態
  • 歌詞語境： でんぐり返しの日々 係形容日子過得翻天覆地、毫無頭緒，用「前滾翻」呢個直觀動作比喩生活嘅混亂感。
  • 例句：
    • 🇯🇵 日： 毎日がでんぐり返しのような忙しさだった。
    • 🇭🇰 粵： 每天都係翻天覆地噉忙，完全停唔低。

【ふり】 (ふり / furi)

  • 詞性： 名詞（振り，常以「〜のふりをする」形式出現）
  • 廣東話解釋： 扮、裝出某種樣子、假裝
  • 歌詞語境： 可哀想なふりをして 係話裝出一副可憐兮兮嘅樣，即係刻意示弱或博同情，有種半開玩笑、帶點自嘲嘅語氣。
  • 例句：
    • 🇯🇵 日： 知らないふりをして、その場をやり過ごした。
    • 🇭🇰 粵： 裝作唔知，就噉捱過咗嗰一關。

【だらけてみた】 (だらけてみた / darakete mita)

  • 詞性： 動詞（だらける 的て形 + みた，表示嘗試做某事）
  • 廣東話解釋： 試試懶散下去、試試放縱鬆懈一下
  • 歌詞語境： だらけてみたけど 係話嘗試過懶散、讓自己鬆弛一下，但「けど」帶出轉折，表示即使噉做，希望之光仍然一直在眼前閃耀。
  • 例句：
    • 🇯🇵 日： 休みの日は少しだらけてみたが、すぐに飽きてしまった。
    • 🇭🇰 粵： 假日試過懶散一下，但好快就覺得悶。

【麦わら】 (むぎわら / mugiwara)

  • 詞性： 名詞
  • 廣東話解釋： 麥稈、草稈；「麦わら帽子」即係麥稈帽、草帽
  • 歌詞語境： 麦わらの帽子の君が 係全首歌最具代表性嘅意象，草帽配合夏天陽光，勾勒出戀人在夏日中嘅鮮明輪廓。
  • 例句：
    • 🇯🇵 日： 彼女は夏になると、いつも麦わら帽子をかぶっていた。
    • 🇭🇰 粵： 佢一到夏天就必定戴住草帽。

【マリーゴールド】 (まりーごーるど / Marīgōrudo)

  • 詞性： 名詞（外來語，英語 Marigold）
  • 廣東話解釋： 萬壽菊、瑪莉金盞花；係一種鮮橙或黃色嘅菊科花朵，常見於夏天
  • 歌詞語境： 揺れたマリーゴールドに似てる 係將戀人比作夏日陽光下搖曳嘅萬壽菊，顏色鮮豔、充滿生命力，係整首歌最核心嘅比喩。
  • 例句：
    • 🇯🇵 日： 庭に咲くマリーゴールドが、風に揺れていた。
    • 🇭🇰 粵： 花園裡盛開嘅萬壽菊，隨著風輕輕搖曳。

【ぎゅっと】 (ぎゅっと / gyutto)

  • 詞性： 副詞（擬態語）
  • 廣東話解釋： 緊緊地、使勁地（擁抱或握住）
  • 歌詞語境： そっとぎゅっと抱きしめて 中「そっと」同「ぎゅっと」並排，前者係輕柔，後者係用力，兩個相反感覺組合出一種溫柔但又緊緊不放嘅擁抱。
  • 例句：
    • 🇯🇵 日： 泣いている子どもをぎゅっと抱きしめた。
    • 🇭🇰 粵： 緊緊抱住咗個喺喊嘅小朋友。

【吐き出せる】 (はきだせる / hakidaseru)

  • 詞性： 動詞（吐き出す 的可能形）
  • 廣東話解釋： 能夠傾瀉出口、可以全說出嚟、能把積壓嘅情緒講晒
  • 歌詞語境： 本当の気持ち全部吐き出せるほど強くはない 係話自己唔夠強大到可以把所有真心說出口，流露出戀愛中壓抑情感、難以坦白嘅脆弱。
  • 例句：
    • 🇯🇵 日： 心の中に溜まったものを、全部吐き出せたら楽になれる。
    • 🇭🇰 粵： 如果可以把心裡積壓嘅嘢全部傾出嚟，就會舒服好多。

【写る】 (うつる / utsuru)

  • 詞性： 動詞
  • 廣東話解釋： 映入、映照、投映（影像留喺某處）
  • 歌詞語境： 目の奥にずっと写るシルエット 係話那個剪影一直映在眼底深處，「目の奥」（眼睛深處）令人感受到一種深刻、揮之不去嘅印記。
  • 例句：
    • 🇯🇵 日： 彼の笑顔が、まぶたの裏にずっと写っている。
    • 🇭🇰 粵： 佢嘅笑臉一直映在眼簾裡，揮之不去。

【シルエット】 (しるえっと / Shiruetto)

  • 詞性： 名詞（外來語，法語 silhouette）
  • 廣東話解釋： 剪影、輪廓、黑影
  • 歌詞語境： 目の奥にずっと写るシルエット 係講戀人嘅剪影一直停留喺眼睛深處，「シルエット」帶出一種朦朧、輪廓分明但又帶點虛幻嘅美感。
  • 例句：
    • 🇯🇵 日： 夕焼けの中に、君のシルエットが浮かんだ。
    • 🇭🇰 粵： 夕陽餘暉之中，你嘅剪影浮現出嚟。

【寄せあい】 (よせあい / yoseai)

  • 詞性： 動詞（寄せ合う 的連用形）
  • 廣東話解釋： 互相靠近、肌膚相依、兩個人身體互相貼近
  • 歌詞語境： 柔らかな肌を寄せあい 係描述兩個人柔軟嘅肌膚互相靠近、緊貼，帶出親密溫柔嘅感覺。
  • 例句：
    • 🇯🇵 日： 寒い夜、二人は肌を寄せあって温もりを分かち合った。
    • 🇭🇰 粵： 凍凍嘅夜裡，兩個人肌膚相依、互相取暖。

【かみしめて】 (かみしめて / kamishimete)

  • 詞性： 動詞（かみしめる 的て形）
  • 廣東話解釋： 細細回味、深深感受、用心品嚐（某種感覺或時刻）
  • 歌詞語境： 少し冷たい空気を2人かみしめて歩く 係講兩個人一邊慢慢感受著那一絲涼意，一邊走路，帶出一種珍視當下、細心品味每一刻嘅態度。
  • 例句：
    • 🇯🇵 日： この幸せな瞬間を、しっかりとかみしめておきたい。
    • 🇭🇰 粵： 我想好好地把這份幸福記住、細細回味。

【じゃ足りない】 (じゃたりない / ja tarinai)

  • 詞性： 慣用表達（〜じゃ足りない：只靠……是不夠嘅）
  • 廣東話解釋： 光靠……不夠、僅憑……不足以表達
  • 歌詞語境： アイラブユーの言葉じゃ足りないからとキスして 係話「我愛你」三個字都不足以表達這份感情，所以選擇用吻代替語言，係全首歌最浪漫嘅一句。
  • 例句：
    • 🇯🇵 日： 言葉じゃ足りないくらい、あなたに感謝している。
    • 🇭🇰 粵： 對你嘅感謝，用語言真係講唔晒。

【遥か】 (はるか / haruka)

  • 詞性： 形容動詞 / 副詞
  • 廣東話解釋： 遙遠、遠在天邊、相距甚遠
  • 歌詞語境： 遥か遠い場所にいても繋がっていたいなあ 係話即使身處遙遠嘅地方，仍然想同對方保持連繫，表達咗跨越距離嘅思念同深情。
  • 例句：
    • 🇯🇵 日： 遥か遠くにいても、あなたのことをいつも想っている。
    • 🇭🇰 粵： 即使身處遙遠嘅地方，我依然時時刻刻掛住你。
