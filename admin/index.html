Edit posts in GitHub

This site uses GitHub’s web editor for post updates because GitHub Pages does not support Decap CMS authentication.

Create a new post

Pick a category, enter a new folder name, then open GitHub with a prefilled index.qmd path.

This creates: posts/<category>/<new-folder>/index.qmd

Open posts root manually

Delete a post

To remove a post safely, choose delete and republish, confirm the prompt, and GitHub will open the workflow page so the site can be rebuilt automatically.

Example: posts/python/intro-to-class
